# mia-mortgage-default
Predicting mortgage default risk in Miami using machine learning, redlining history, and climate data
# Miami Mortgage Default Risk — ML Pipeline

## Research Question
Can machine learning predict which Miami mortgages will default better than 
traditional models — and does adding climate and historical discrimination data 
reveal that minority neighborhoods carry more hidden risk than lenders realize?

## Methods
- Logistic Regression (baseline)
- Random Forest
- XGBoost + SHAP interpretability
- ARIMA time series forecasting
- Choropleth mapping (geopandas)

## Data Sources
- HMDA 2018–2022 (Miami-Dade County)
- ACS Census tract demographics
- HOLC redlining maps (1930s)
- FEMA National Flood Hazard Layer
- FEMA NFIP insurance coverage data
